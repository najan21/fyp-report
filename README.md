# fyp-report

Web version of the CDE4301 Design and Innovation final report, **FTS-401: Red Dot Mobility (Electric Mobility)**, published with GitHub Pages.

## Editing

- Report text, tables and figure captions: `index.md` (Markdown)
- Images: `assets/images/`
- Page layout and sidebar contents: `_layouts/report.html`
- Styling: `assets/css/style.css`

Every commit to `main` rebuilds the site automatically.

## Interim presentation (`slides/`)

Web version of `CDE4301A_Interim_Presentation.pptx`, live at https://najan21.github.io/fyp-report/slides/

- Generated from the .pptx: every image, line and text box keeps its original position on a 1920×1080 stage, using the fonts embedded in the deck (`slides/fonts/`).
- Intro video: `slides/media/intro.mp4`, trimmed to the same segment as in PowerPoint and re-encoded so it starts playing immediately.
- Navigate with arrow keys, click, swipe or scroll; `F` for full screen; `#5` in the URL jumps to slide 5.
- The original .pptx is in the folder and linked from the download button.
